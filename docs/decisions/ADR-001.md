# ADR-001 — Persistent Repository-Based Project Memory

Status: Accepted
Date: 2026-09-27

## Context
Conversation context can be truncated or unavailable across sessions. The project therefore needs an authoritative memory layer outside the chat.

## Decision
Use repository-managed Markdown/YAML records as the durable source of project context, with AI_CONTEXT.md as the recovery entry point and PROJECT_STATE.md as the current-state authority.

## Consequences
- Project continuity no longer depends solely on chat history.
- State and history become auditable through Git.
- Documentation must be updated as part of relevant changes.
- The recovery process must avoid inventing undocumented history.
