# ADR-004 — Source-Neutral Context Engine

- Status: Accepted
- Date: 2026-09-27

## Context

The initial World Book resolver correctly established deterministic routing, but extending that resolver directly with Long Memory, semantic retrieval, global budgeting, and placement would create a source-specific orchestration layer.

## Decision

Introduce a source-neutral Context Engine with four separable responsibilities:

1. sources produce candidates;
2. filters/ranking select candidates;
3. budgets constrain selected context;
4. Prompt Assembly places selected context.

World Book and Long Memory remain separate sources. Semantic retrieval is an optional candidate provider.

## Rationale

This prevents a growing World Book implementation from becoming a general-purpose context engine and allows future retrieval sources without changing the final prompt contract.

## Rejected

- making Long Memory a World Book field;
- embedding ranking, retrieval, and placement in one resolver;
- mandatory vector search;
- allowing external resource text to recursively create system instructions.
