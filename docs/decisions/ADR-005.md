# ADR-005 — Model Operating Preset as a Turn-Level Operating Protocol

- Status: Accepted
- Date: 2026-09-27

## Context

The original `PRESET-001` primarily described repository continuity, World Book retrieval, and source-of-truth rules. It did not define the model's operating loop precisely enough: how to interpret a request, select a work mode, choose the next action, verify the result, and determine completion.

Open-source systems examined during this revision show that mature prompt architectures separate general model behavior from dynamically loaded context. SillyTavern's Prompt Manager separates the main/system prompt from dynamically positioned World Info and other prompt components. Tavo treats presets as core behavior patterns and keeps Long Memory and Lore Book as distinct systems. Continue treats rules as an ordered system-message layer, while Aider and OpenHands emphasize concise task-relevant context, planning/decomposition, tool execution, and verification-oriented workflows.

## Decision

Keep `PRESET-001` as the permanent baseline operating preset, but redefine it as a compact **turn-level operating protocol**.

The preset must define:

1. role and mission;
2. an ordered operating loop;
3. decision and conflict rules;
4. context discipline;
5. research/evidence behavior;
6. project/code change discipline;
7. completion criteria;
8. output discipline;
9. continuity/recovery behavior;
10. source-of-truth mapping;
11. mandatory per-turn injection.

Task-specific knowledge, World Book entries, Long Memory, Skills, and Resources remain outside the preset.

## Rationale

This keeps the baseline prompt stable and small while making model behavior explicit. It also prevents the preset from becoming a second World Book or a duplicate project manual.

## Rejected

- putting all project knowledge into the preset;
- encoding every task-specific workflow in the preset;
- making the preset responsible for World Book retrieval implementation;
- treating discovery, file modification, or a proposed plan as proof of completion;
- injecting large skills or resources directly into the baseline preset.
