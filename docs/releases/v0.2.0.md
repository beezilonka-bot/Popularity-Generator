# v0.2.0 — Context Engine Foundation

## Added

- MOD-012 — Context Engine & Prompt Assembly.
- LOOP-004 — Context Retrieval & Prompt Assembly.
- ADR-004 — Source-Neutral Context Engine.
- deterministic candidate/ranking/budget primitives;
- scoped and conditional World Book resolution;
- bounded recursive activation with cycle/step limits;
- separate Long Memory registry/source;
- canonical Prompt Assembly section order;
- global context-budget enforcement.

## Solved

- World Book no longer owns all context orchestration.
- Long Memory is structurally separated from World Book.
- Runtime configuration is read from repository configuration instead of duplicated defaults.
- Prompt placement is separated from retrieval.

## Not Yet Complete

- full end-to-end execution verification;
- semantic retrieval;
- automatic memory promotion;
- complete Skill content resolution;
- production model adapter.
