# MOD-012 — Context Engine & Prompt Assembly

## Purpose

Provide a source-neutral runtime that retrieves, filters, ranks, budgets, and assembles per-turn context.

## Scope

Owns:
- common candidate model;
- deterministic ranking and selection;
- global context-budget enforcement;
- prompt section ordering;
- Long Memory as a separate context source;
- World Book integration.

Does not own:
- model inference;
- web search;
- content generation;
- authoritative project state.

## Boundary

World Book and Long Memory produce candidates. The Context Engine decides which candidates are usable. The Prompt Assembler decides where selected material is placed.

## Acceptance

- retrieval sources remain independently replaceable;
- global budget is enforced;
- placement does not change retrieval;
- activation remains traceable;
- semantic retrieval can be added without changing prompt assembly.
