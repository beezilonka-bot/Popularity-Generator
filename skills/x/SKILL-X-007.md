# SKILL-X-007 — Research-to-Post Workflow

## Goal
Use current evidence to improve a post without turning research into bloated output.

## Workflow
1. Define topic, audience, objective, and factual boundaries.
2. Search for current primary/credible sources and relevant X examples when needed.
3. Extract only facts, angles, patterns, and useful phrasing characteristics.
4. Separate source facts from interpretation.
5. Select the simplest content structure.
6. Draft.
7. Fact-check claims.
8. Compress and remove generic language.
9. Run the quality gate.

## Rule
Research is an input to writing, not a substitute for writing.
