# SKILL-X-003 — Thread Architecture

## Goal
Turn one substantial idea into a sequence where every post advances the argument.

## Structure
Hook → context → key insight(s) → evidence/examples → synthesis → optional CTA.

## Rules
- One job per tweet.
- Each tweet should remain understandable on its own where practical.
- Every tweet must advance the thread; delete filler.
- Use numbering only when it improves navigation.
- Thread length is determined by the idea, not a fixed "viral" number.

## Quality Test
Remove any tweet that does not add information, tension, evidence, or narrative progress.
