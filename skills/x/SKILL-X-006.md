# SKILL-X-006 — Content Pattern Selection

## Goal
Choose a structure based on the content rather than forcing every topic into one formula.

## Patterns
- Observation → implication
- Problem → diagnosis → solution
- Before → after → bridge
- Case study → lesson
- List → explanation
- Myth → evidence → nuance
- Story → turning point → lesson
- Framework → steps → application
- News/event → fact → significance → context

## Selection Rule
Use the simplest pattern that fully communicates the idea. A pattern is a tool, not a requirement.
