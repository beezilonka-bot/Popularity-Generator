# SKILL-X-009 — Quality Gate

## Preflight
- [ ] One clear primary idea
- [ ] Hook matches the actual content
- [ ] Claims are supported or clearly framed
- [ ] No invented numbers, quotes, results, or experiences
- [ ] No unnecessary filler
- [ ] Voice matches the requested style
- [ ] Thread progression is logical, if applicable
- [ ] Character limits are satisfied for the requested X format
- [ ] CTA, if present, is relevant and not generic engagement bait
- [ ] Final text reads naturally aloud

## Failure Handling
If a check fails, revise only the failing dimension first. Do not regenerate the entire post blindly.
