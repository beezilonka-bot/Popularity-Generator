# SKILL-X-010 — Content Repurposing

## Goal
Transform existing source material into X-native content without merely shortening it.

## Workflow
Source → extract thesis → identify strongest evidence/story → choose X-native angle → draft → compress → fact-check.

## Rules
- Preserve the source's factual meaning.
- Do not invent a stronger claim than the source supports.
- One source can yield multiple distinct angles, but each angle must be materially different.
