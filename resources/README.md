# Resource Library

The resource library stores supporting material and provenance metadata.

## Resource types

- source — authoritative or primary source;
- repository — open-source repository or implementation;
- documentation — product/API/platform documentation;
- research — research paper or structured research note;
- example — short, project-owned example;
- dataset — structured input for analysis;
- reference — other useful background material.

## Rule

Resources support reasoning; they do not automatically become project facts.

Each resource should record:

- permanent resource ID;
- title;
- type;
- URL/path;
- source owner;
- access/update date when relevant;
- evidence/status classification;
- what task it supports.

Large source material stays out of normal prompts and is fetched on demand.
