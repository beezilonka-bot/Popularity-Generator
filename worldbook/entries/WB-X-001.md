# WB-X-001 — X Post Writing

When the task is to write a single X post, use the smallest applicable X-writing skill set.

Operational rules:
- establish one primary idea;
- put the highest-value statement early;
- remove setup the reader can infer;
- use concrete details where available;
- do not invent facts, numbers, quotes, results, or personal experience;
- match the requested voice instead of imposing a generic AI style;
- run the X quality gate before final output.
