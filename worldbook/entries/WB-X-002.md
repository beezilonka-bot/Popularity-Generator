# WB-X-002 — X Thread Writing

When the task is to write an X thread, use a progressive structure:

Hook → context → key insight(s) → evidence/examples → synthesis → optional CTA.

Give each post one job. Remove posts that do not add information, evidence, tension, or narrative progress.
