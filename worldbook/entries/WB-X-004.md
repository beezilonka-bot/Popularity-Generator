# WB-X-004 — Research Resource Routing

When a task needs current facts, source discovery, open-source methods, or writing research:

- search current primary or credible sources;
- for implementation methods, inspect the repository or documentation rather than relying on summaries;
- record source identity and date where relevant;
- extract reusable principles rather than copying large source passages;
- distinguish observed source material from project conclusions;
- pass only the relevant research into the writing context.

Current research references include SillyTavern World Info documentation and open-source World Book retrieval implementations.
